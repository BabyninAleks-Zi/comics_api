# XKCD Comics VK Publisher

Проект состоит из нескольких скриптов для получения комиксов XKCD и публикации их в группу ВКонтакте.

Программа позволяет:

* Получать случайный комикс XKCD через публичное API
* Сохранять изображение локально в папку `images`
* Публиковать пост с изображением и подписью в VK

Проект разбит на несколько модулей, каждый из которых отвечает за свою задачу.

```python
comics_publisher.py     # Получение данных XKCD и запуск публикации
vk_publisher.py         # Загрузка изображения и публикация в VK
```

---

## Как установить

Перед началом работы необходимо создать виртуальное окружение и установить зависимости.

```bash
python -m venv venv
venv\Scripts\activate
```

Установите необходимые библиотеки:

```bash
pip install -r requirements.txt
```

---

## Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```text
VK_API_TOKEN      # Токен VK API
VK_GROUP_ID       # ID группы VK (без знака минус)
```

---

## Как использовать

### Публикация случайного комикса

Скрипт:

* Запрашивает данные случайного комикса XKCD
* Скачивает изображение и сохраняет в `images`
* Публикует пост в VK с подписью из поля `alt`

Запуск:

```bash
python comics_publisher.py
```
